# Task Management Dashboard

A responsive task management dashboard developed as part of the Gupio Campus Placement Development Assignment.

## Features

- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Task status management
- Priority management
- Due date management
- Search tasks
- Filter tasks by status
- Task statistics
- Form validation
- Error handling
- Responsive design
- LocalStorage data persistence

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

Open `index.html` using Live Server or any modern web browser.
